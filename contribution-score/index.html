Evaluated is not the same as exact. A range is a finished result under incomplete evidence, not a job waiting to finish. Identical inputs and the same policy produce the same result; retrying cannot fill missing facts.

What is checked, stored and protected?

Admissible input

The current model requires explicit Ranked mode, twelve unique players, six per team, common-clock snapshots and explicit death/objective lists. At least two snapshots must cover at least 60 seconds and half the match. Missing is different from an explicitly empty event list.

Bounded execution

Authorization precedes work. Shared coordination prevents duplicate inference; time, size and request budgets bound it. A busy service may return pending. Missing metadata is not silently acquired, and an unsupported mode is not relabelled.

Durable evaluation

Store the result, event evidence, model/policy identity and input hash. Ordinary views reuse the stored match evaluation. Raw-input retention is separate: a hash identifies input but cannot reconstruct expired metadata.

FIRST, MEASURE POSITIVE WORK

Three kinds of work. One bounded scale.

For each component, divide eligible work per 180 observed seconds by a fixed reference rate. Call that nonnegative ratio r. Convert it to points with diminishing returns.

component points= maximum × r1 + r

r = 0 → no points
r = 1 → half the component maximum
r = 3 → three quarters

THEN, ACCOUNT FOR SUPPORTED MAP GAINS

A death is not automatically a deduction.

At an enemy structure completion or reported Rejuvenator claim, a dead player receives a limited concession share only if their team has more players dead. Toggle the players to see the allocation.

This sandbox repeats one known team-state pattern. Real events each use their own clock and team state. Each supported structure/claim is one event unit, not a measured utility value.

YOUR SHARE OF ONE EVENT
max(0, own dead − enemy dead)6 × own dead
(3 − 1) / (6 × 3) = 0.1111

One ninth of an event for you; one third across the three dead teammates. The remainder stays unallocated.

L = Σ shares × 180 / T
P = 1 / (1 + 0.4 × L / CO)

Concession units 0.1111Factor P 0.9529

Living players receive zero concession share. No enemy gain, equal dead counts or fewer own dead also means zero. P is a declared scoring factor, not a time-alive percentage or causal probability.

    How the rank range is calculated

    Best rank = 1 + rivals definitely above you.
    Worst rank = 1 + rivals who could be above you.

    “Above” is strict: equal values may share a rank. Conservative bounds need not all be jointly attainable. Full placement is emitted only for an entirely exact roster; a single player’s rank bounds can still coincide.

    Not a confidence interval. Not an unfinished computation.

    These bounds represent unresolved recorded evidence under the model. They do not quantify all statistical or causal uncertainty. “Exact” is conditional on the formula and clock proxy, not certainty about someone’s true impact. Display ranges round outward; all calculations use full precision.

    How often did this happen in the existing evaluation?

    In 18,741 reused Ranked matches (224,892 player-games), 179,828 scores were exact under the model and 45,064 were bounded: approximately 80% / 20%. Bounded intervals averaged 1.04 points wide, with a maximum of 13.01. There were 4,111 completely exact rosters; 18,375 matches still had at least one guaranteed top-ranked player, with possible ties.

    This was previously inspected research data, not an independent holdout or a claim that future competitions will have the same coverage. The toy match above intentionally makes uncertainty easy to see; it is not a typical-width claim.

    06

    BEFORE REUSING THE SYSTEM

    Keep contribution and a league rating distinct.

    This is a transparent accounting model, not a finished universal performance rating. Reuse starts by deciding what the new score is meant to represent.

    01 / PURPOSE

    What is being ranked?

    One-match contribution, opponent-adjusted performance and long-term skill are different targets. Match-time rank and peer performance are not inputs here. A contextual successor needs its own policy, without current-rank leakage or circular peer-score feedback.

    02 / ADMISSION

    Which games qualify?

    The current model accepts Ranked only. Tournament or custom-lobby admission is not a UI switch. Validate metadata fields, clock semantics and coverage in the intended population before admitting a new mode.

    03 / INCOMPLETE EVIDENCE

    Must every result be one number?

    Current policy retains intervals. Alternatives include declining a point score or introducing an explicit estimation model. A midpoint, a lower-bound ranking or a guessed duration is a new convention, not unchanged v8. Publish and validate that choice.

    04 / VALIDATION

    Does the policy travel?

    Validate on genuinely held-out target-population games, including roles, heroes, zero work, outliers and missingness. The 40/40/20 weights, historical references and concession factor are declared conventions, not proof of optimal causal value.

    What this metadata cannot establish

    Positioning and spatial control · exact pickup clocks · urn/camp timelines · individual per-target attribution · trades and clutches · useful sacrifices · death-caused soul transfers.

    Unobserved is not the same as zero. These limitations remain even when the formula returns an exact numerical score.
